# Утренний дайджест

Каждое утро собирает новости за сутки из RSS и Hacker News, отбирает интересные
по твоему профилю и присылает 10 штук в Telegram.

## Как устроено

```
RSS (23 ленты) + Hacker News
        ↓  collect.py     — параллельный сбор, окно 24 часа
        ↓  dedupe.py      — схлопывание статей об одном событии
        ↓  storage.py     — отсев того, что уже отправляли
        ↓  score.py       — Haiku оценивает 300-600 заголовков батчами
        ↓  summarize.py   — Sonnet пишет карточки для топ-10
        ↓  deliver.py     — отправка в Telegram
```

Ключевое решение — двухступенчатый отбор. Сначала дешёвая модель просматривает
все заголовки пачками по 40 штук, потом дорогая работает только с десяткой
финалистов и полными текстами статей. Поштучный прогон всего потока через
сильную модель стоил бы в разы дороже и занял бы минуты вместо секунд.

Векторов и Postgres здесь нет намеренно: дедупликация по нормализованным
заголовкам ловит почти все дубли, а SQLite хватает с большим запасом.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:

**ANTHROPIC_API_KEY** — на console.anthropic.com, раздел API Keys.

**TELEGRAM_BOT_TOKEN** — напиши [@BotFather](https://t.me/BotFather), команда
`/newbot`, придумай имя. Токен придёт в ответ.

**TELEGRAM_CHAT_ID** — напиши своему боту любое сообщение, потом открой
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id":...}`.
Без первого сообщения бот не имеет права тебе писать — это ограничение Telegram.

## Запуск

```bash
python main.py --collect    # что нашлось в источниках, без обращений к модели
python main.py --dry-run    # полный дайджест в консоль, без отправки
python main.py              # боевой прогон
python test_offline.py      # тесты логики, сеть и ключи не нужны
```

Начни с `--collect`: если источники отдают сотни заголовков, значит сбор
работает и можно тратить деньги на скоринг.

## Настройка под себя

Всё в `config.py`:

| Параметр | Что делает |
|---|---|
| `INTEREST_PROFILE` | Профиль интересов обычным текстом. Главная ручка. |
| `RSS_FEEDS` | Ленты. Добавляй свои, удаляй лишние. |
| `MIN_SCORE` | Порог отсечения. Подними до 7, если много проходного. |
| `DIGEST_SIZE` | Сколько новостей в выпуске. |
| `HN_MIN_POINTS` | Порог популярности для Hacker News. |
| `WINDOW_HOURS` | Глубина окна в часах. |

Профиль интересов — обычный текст, а не список ключевых слов: модель понимает
формулировки вроде «интересны траектории компаний, а не отчётность корпораций».
Правь его первые пару недель, это даст больший эффект, чем любые другие настройки.

## Деплой

```bash
fly launch --no-deploy
fly volumes create digest_data --size 1
fly secrets set ANTHROPIC_API_KEY=... TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...
fly deploy
```

В `fly.toml` добавь монтирование тома:

```toml
[mounts]
  source = "digest_data"
  destination = "/data"
```

Том нужен, чтобы история отправленного пережила деплой — иначе после каждого
обновления вернутся вчерашние новости. Время запуска и часовой пояс правятся
в `Dockerfile` (`TZ` и строка crontab).

Подойдёт и любой VPS: там достаточно обычного cron со строкой
`0 8 * * * cd /path/to/digest && /path/to/venv/bin/python main.py`.

## Сколько стоит

Хостинг около $5 в месяц. Claude API при одном прогоне в сутки — доллар-два
в месяц: скоринг 500 заголовков на Haiku стоит центы, десяток карточек на
Sonnet тоже. Остальные API бесплатные и без ключей.

## Известные ограничения

**RSS не покрывает всё.** Часть изданий отдаёт в ленте только анонс, часть
закрывается от ботов через Cloudflare. Такие ленты будут молча падать в лог
с предупреждением — это нормально, дайджест соберётся из остальных.

**Дедупликация не идеальна.** Два материала об одном событии с сильно разными
заголовками останутся двумя пунктами. Порог `SIMILARITY_THRESHOLD` в `dedupe.py`
можно подкрутить, но слишком низкий начнёт склеивать разные новости.

**SQLite нужен нормальный диск.** На некоторых сетевых файловых системах
блокировки не работают и база падает с `disk I/O error`. Переменная `DIGEST_DB`
позволяет положить базу куда угодно.

## Что можно добавить потом

Кнопки 👍/👎 под каждой новостью: бот принимает callback, копит реакции, раз
в неделю модель переписывает `INTEREST_PROFILE` с их учётом. Это заметно проще
и прозрачнее, чем обучение на эмбеддингах, и профиль всегда можно поправить руками.
